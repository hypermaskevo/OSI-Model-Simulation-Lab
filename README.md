# OSI-Model-Simulation-Lab
Welcome to this hands-on project! 🎉 This lab simulates the OSI Model using Cisco Packet Tracer, focusing on DHCP traffic analysis and Layer 7 interaction using PC and Server communication.
![image](https://github.com/user-attachments/assets/79a6605c-4a3b-4248-8fb8-2170ef9a4bd6)
🧪 Lab Objective
This project is designed to help you:

👓 Analyze network traffic across OSI Layers using Simulation Mode

📶 Generate and inspect Layer 7 (Application Layer) traffic

🔁 Use DHCP to assign IP addresses dynamically

🧠 Understand how different layers of the OSI model work together in real-time

🛠️ What You'll Learn
🔍 Identify OSI layers involved in DHCP communication

🔗 Use commands like ipconfig /release and ipconfig /renew to simulate traffic

🌐 Understand packet details at each layer (e.g., IP, Ethernet, UDP)

🖥️ Tools Used
Cisco Packet Tracer

Basic network topology (PC, Switch, Router, Server)

Command Line Interface (CLI)

📸 Screenshot

🚀 How to Run
Open the .pkt file in Cisco Packet Tracer.

Switch to Simulation Mode.

Use the Command Prompt on PC1:

bash
